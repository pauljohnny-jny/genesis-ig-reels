NOT GO: எத்தனை turns? Thread plug gauge GO / NOT GO – internal thread-ஐ check செய்வது எப்படி.

ISO 1502-படி இரண்டு gauge-ம் கையால், அதிக force இல்லாமல். GO end workpiece thread-ன் முழு நீளமும் போக வேண்டும்; போகவில்லை என்றால் thread reject. NOT GO end அணுகக்கூடிய ஒவ்வொரு முனையிலும் (through hole-ல் இரண்டு முனை, blind hole-ல் ஒன்று) அதிகபட்சம் 2 turns வரை நுழையலாம் (turns-ஐ gauge-ஐ வெளியே எடுக்கும்போது எண்ணுங்கள்); 2 turns-க்கு மேல் போனால் reject. Thread நீளம் 3 threads அல்லது அதற்குக் குறைவு என்றால் NOT GO முழுவதும் கடந்து போகக் கூடாது. GO end minimum pitch Ø (virtual) மற்றும் minimum major Ø-ஐ check செய்கிறது; NOT GO end maximum pitch Ø-ஐ check செய்கிறது. GO முழு நீளமும் போய், NOT GO இந்த வரம்புக்குள் நின்றால் screw-plug checks pass. கூடுதல் விவரம்: இந்த இரண்டு gauge-ம் minor Ø-ஐ check செய்வதில்லை; அதற்குத் தனி plain GO / NOT GO plug gauge (ISO 1502 clause 7.2.3). Gauge-களை wear-க்கு regular-ஆக check செய்யுங்கள். Assumptions: ISO metric internal thread (ISO 1502:1996); reel drawing schematic. VMC operator-கள் gauge-ஐ wrench-ஆல் திருகாதீர்கள்.
